# MeetStream for Cursor

MeetStream is meeting-bot infrastructure. A bot joins a Zoom, Google Meet or Microsoft Teams call as a visible participant, records it and transcribes it. Ask your agent to send a bot to a meeting link, then get the transcript, an AI summary, the recording, the participants and the in-meeting chat. Build tracks: 1) the Recording bot, with post-call or real-time transcription; 2) the Bridge server, for an agent in the meeting on your own stack; 3) the hosted Agents API for voice agents (bring-your-own-infra and local-agent options are coming soon). Zoom bots join through your own Zoom app with an OBF or ZAK token, so set up a Zoom Meeting SDK app before the first Zoom bot. Sign in once in the browser through the hosted MeetStream MCP server; no API key is pasted into the chat.

## Install

Install **MeetStream** from the Cursor Marketplace. To test it locally, copy this folder to `~/.cursor/plugins/local/meetstream` and run **Developer: Reload Window**.

## Sign in

The plugin connects to the hosted MeetStream MCP server at https://mcp.meetstream.ai/mcp. The first time a MeetStream tool runs, your client opens app.meetstream.ai in the browser. Sign in (or create an account) and click **Allow**. No API key is pasted into the chat.

## Try it

- "Send a bot to my next meeting and give me notes afterwards"
- "Get the transcript and action items from my last recorded meeting"
- "Show my recent MeetStream bots and their status"
