# MeetStream API endpoints: Bots

> Part of [`endpoints.md`](endpoints.md), split so each file stays under 20 KB.

## Bots

| Method and path | What it does | Request | Docs |
|---|---|---|---|
| `POST /api/v1/bots/create_bot` | Send a bot to a Zoom, Google Meet or Microsoft Teams meeting, now or at join_at. | body: **meeting_link** + 27 optional; responses: 200, 400, 401, 403, 404, 409, 422, 429, 500, 503, 507 | [Create Bot](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/create-bot) |
| `PATCH /api/v1/calendar/scheduled_bots/{bot_id}` | Change the join time of a bot that is already scheduled, instead of deleting it and creating a replacement. | body: **scheduled_join_time**; responses: 200 | [Reschedule Bot](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/reschedule-bot) |
| `DELETE /api/v1/calendar/scheduled_bots/{bot_id}` | Cancel a bot scheduled for a future meeting so it never dials in, for when the meeting is called off or moved. | responses: 200 | [Delete Scheduled Bot](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/delete-scheduled-bot) |
| `GET /api/v1/bots/{bot_id}/status` | Check where a meeting bot is in its lifecycle, from joining and in-meeting through recording to stopped, without waiting for the next webhook. | responses: 200 | [Get Bot Status](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/get-bot-status) |
| `GET /api/v1/bots/{bot_id}` | Fetch a bot's record: configuration, status, status timeline and artifact availability. | responses: 200, 403, 404 | [Get Bot](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/get-bot) |
| `GET /api/v1/bots/{bot_id}/detail` | Participants activity can be fetched from the link in the response payload. | responses: 200, 403, 404 | [Get Bot Details](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/get-bot-details) |
| `GET /api/v1/bots/{bot_id}/get_audio` | Get a download URL for the mixed meeting audio the bot recorded, the single blended track containing every participant in the call. | responses: 200 | [Get Bot Audio](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/get-bot-audio) |
| `GET /api/v1/bots/{bot_id}/get_video` | Get a download URL for the full meeting video the bot recorded on Zoom, Google Meet or Microsoft Teams. | responses: 200 | [Get Bot Video](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/get-bot-video) |
| `GET /api/v1/bots/{bot_id}/get_recording_streams` | List the per-participant video recordings from a meeting, one stream per participant, each with its own download URL. | responses: 200 | [Get Recording Streams](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/get-recording-streams) |
| `GET /api/v1/bots/{bot_id}/get_audio_streams` | List the per-participant audio recordings from a meeting, one track per participant, with the availability status of each. | responses: 200 | [Get Audio Streams](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/get-audio-streams) |
| `GET /api/v1/bots/{bot_id}/remove_bot` | Ask a bot to leave its meeting. | responses: 200, 404 | [Remove Bot](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/remove-bot) |
| `POST /api/v1/bots/{bot_id}/remove_bot` | POST form of Remove Bot. | responses: 200, 404 | [Remove Bot (POST)](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/remove-bot-post) |
| `GET /api/v1/bots/{bot_id}/stop_status` | Check the progress of a stop request without stopping the bot again: requested, acknowledged, stopped, force-stopped or failed. | responses: 200, 404 | [Get Stop Status](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/get-stop-status) |
| `POST /api/v1/bots/{bot_id}/pause_recording` | Temporarily pauses capture for a bot that is in a Google Meet, Zoom or Microsoft Teams meeting. | responses: 200, 403, 404, 409, 429, 503 | [Pause Bot Recording](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/pause-bot-recording) |
| `POST /api/v1/bots/{bot_id}/resume_recording` | Resumes normal video, audio, stream, and real-time transcription capture for a paused bot in a Google Meet, Zoom or Microsoft Teams meeting. | responses: 200, 403, 404, 409, 429, 503 | [Resume Bot Recording](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/resume-bot-recording) |
| `GET /api/v1/bots/{bot_id}/get_speaker_timeline` | Get an ordered timeline of who spoke and when, with start and end times and the text of each speaking turn, for diarization and analytics. | responses: 200, 403, 404 | [Get Speaker Timeline](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/get-speaker-timeline) |
| `GET /api/v1/bots/{bot_id}/get_chats` | Read the in-meeting chat the bot captured, with the sender, timestamp and text of every message posted during the call. | responses: 200 | [Get Bot Chats](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/get-bot-chats) |
| `GET /api/v1/bots/{bot_id}/screenshots` | List the screenshots captured for a bot, newest first, with a one-hour download URL for each. | query: action, continuation_token, limit, meta, recorded_at_after, recorded_at_before; responses: 200, 403, 404 | [Get Bot Screenshots](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/get-bot-screenshots) |
| `GET /api/v1/bots/{bot_id}/screenshots/{id}` | Fetch one screenshot by id, with a fresh one-hour download URL. | responses: 200, 400, 403, 404 | [Get Screenshot](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/get-bot-screenshot) |
| `GET /api/v1/bots/{bot_id}/get_participants` | List everyone who was in the meeting, with join and leave times, so you can attribute speech and build attendance records. | responses: 200 | [Fetch Participants](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/fetch-participants) |
| `DELETE /api/v1/bots/{bot_id}/delete` | Permanently delete a bot's stored recordings, transcripts and other media. | responses: 200 | [Delete Data](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/delete-bot-data) |
| `GET /api/v1/bots` | List every bot in the workspace, filtered by status, platform, date range or your own custom attributes, for dashboards and reconciliation. | query: cursor, custom_attr[...], from, limit, platform, status, to; responses: 200 | [List Bots](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/list-bots) |
| `POST /api/v1/bots/{bot_id}/send_message` | Post a chat message into a live meeting as the bot, so your agent can answer a question, share a link or confirm an action in the call. | body: **message** + 1 optional; responses: 200, 400, 403, 404, 409, 429, 503 | [Send Message](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/send-message) |
| `POST /api/v1/bots/{bot_id}/send_image` | Send an image into a live meeting as the bot's video feed, with a display duration. | body: img_url, img, display_duration, metadata; responses: 200, 400, 403, 404, 409, 429 | [Send Image](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/send-image) |
| `POST /api/v1/bots/{bot_id}/send_command` | Send a command to a bot that is in a live meeting. | body: **command**; responses: 200, 400, 403, 404, 409, 429, 501, 502, 503 | [Send Command](https://docs.meetstream.ai/api-reference/api-endpoints/bot-endpoints/send-command) |

## Transcription

| Method and path | What it does | Request | Docs |
|---|---|---|---|
| `GET /api/v1/transcript/{transcript_id}/get_transcript` | Fetch a finished transcript by id, speaker labelled, with optional raw word-level timings for alignment, search and highlighting. | query: raw; responses: 200, 403, 404, 409, 422, 500 | [Get Transcription](https://docs.meetstream.ai/api-reference/api-endpoints/transcription/get-transcription) |
| `POST /api/v1/bots/{bot_id}/transcribe` | Run transcription on a bot's recording using Deepgram, AssemblyAI, Sarvam, Interfaze (formerly JigsawStack), Smallest AI or the MeetStream engine, with per-provider options. | body: **provider** + 1 optional; responses: 200 | [Transcribe](https://docs.meetstream.ai/api-reference/api-endpoints/transcription/transcribe-bot-audio) |
| `GET /api/v1/bots/{bot_id}/transcriptions` | List every transcription job for a bot, with the provider used and its status, so you can pick up the finished transcript. | responses: 200 | [Transcriptions](https://docs.meetstream.ai/api-reference/api-endpoints/transcription/get-bot-transcriptions) |
| `GET /api/v1/bots/{bot_id}/get_transcript` | Fetch the first transcript created for a bot by its bot ID, without looking up the transcript ID first. | query: raw; responses: 200, 403, 404, 409, 422, 500 | [Get Transcript by Bot ID](https://docs.meetstream.ai/api-reference/api-endpoints/transcription/get-transcript-by-bot-id) |

## Calendar

| Method and path | What it does | Request | Docs |
|---|---|---|---|
| `POST /api/v1/calendar/create_calendar` | Connect a Google Calendar so MeetStream can read its events and send bots to the meetings on it automatically. | body: **google_client_id**, **google_client_secret**, **google_refresh_token** + 1 optional; responses: 200 | [Create Calendar](https://docs.meetstream.ai/api-reference/api-endpoints/calendar/create-calendar) |
| `DELETE /api/v1/calendar/disconnect` | Disconnect a calendar account. | body: provider, account_id, purge_events; query: account_id, provider, purge_events; responses: 200, 400, 404, 409 | [Disconnect Calendar](https://docs.meetstream.ai/api-reference/api-endpoints/calendar/disconnect-calendar) |
| `GET /api/v1/calendar/calendars` | List the calendars on every connected Google and Outlook account, so you can show them in your own settings screen. | query: account_id, provider; responses: 200, 400, 404 | [Get Calendars](https://docs.meetstream.ai/api-reference/api-endpoints/calendar/get-calendars) |
| `GET /api/v1/calendar/connections` | List the Google and Outlook accounts connected for calendar sync, with the status of each. | query: cursor, limit; responses: 200, 400 | [List Calendar Connections](https://docs.meetstream.ai/api-reference/api-endpoints/calendar/list-calendar-connections) |
| `GET /api/v1/calendar/connections/{provider}/{account_id}` | Get one connected calendar account by provider and email address. | responses: 200, 400, 404 | [Get Calendar Connection](https://docs.meetstream.ai/api-reference/api-endpoints/calendar/get-calendar-connection) |
| `DELETE /api/v1/calendar/connections/{provider}/{account_id}` | Disconnect one calendar account, and by default delete its synced events and the bots scheduled from them. | query: purge_events; responses: 200, 400, 404 | [Delete Calendar Connection](https://docs.meetstream.ai/api-reference/api-endpoints/calendar/delete-calendar-connection) |
| `POST /api/v1/calendar/schedule/{event_id}` | Schedule a bot for one calendar event so it joins that meeting automatically when it starts. | responses: 200 | [Schedule Event](https://docs.meetstream.ai/api-reference/api-endpoints/calendar/schedule-event) |
| `DELETE /api/v1/calendar/schedule/{event_id}` | Cancel the bot scheduled for a single calendar event, leaving the rest of that calendar's auto-scheduling untouched. | responses: 200 | [Remove Schedule Event](https://docs.meetstream.ai/api-reference/api-endpoints/calendar/remove-schedule-event) |
| `GET /api/v1/calendar/events` | Fetch the synced events for a connected calendar, including each meeting link and whether a bot is already scheduled for it. | responses: 200 | [Fetch/Sync Events](https://docs.meetstream.ai/api-reference/api-endpoints/calendar/fetch-sync-events) |
| `POST /api/v1/calendar/auto-schedule/enable` | Turn on automatic scheduling so a bot joins every eligible meeting on a connected calendar without a call per event. | body: default_bot_config; responses: 200 | [Setup Cron](https://docs.meetstream.ai/api-reference/api-endpoints/calendar/setup-cron) |
| `POST /api/v1/calendar/auto-schedule/disable` | Turn off automatic scheduling for a connected calendar. | responses: 200 | [Disable Cron](https://docs.meetstream.ai/api-reference/api-endpoints/calendar/disable-cron) |
| `GET /api/v1/calendar/auto-schedule/settings` | Returns whether calendar auto-scheduling is enabled and the default bot config used for automatically scheduled bots. | responses: 200 | [Get Auto-Schedule Settings](https://docs.meetstream.ai/api-reference/api-endpoints/calendar/get-auto-schedule-settings) |
| `GET /api/v1/calendar/scheduled_bots` | Returns all bots with a scheduled join time in the future - both join_at bots and calendar-scheduled bots. | query: limit; responses: 200 | [List Scheduled Bots](https://docs.meetstream.ai/api-reference/api-endpoints/calendar/list-scheduled-bots) |
| `POST /api/v1/calendar/create_outlook_calendar` | Connect an Outlook / Microsoft 365 calendar using an Azure app registration's refresh-token flow. | body: **microsoft_client_id**, **microsoft_client_secret**, **microsoft_refresh_token** + 1 optional; responses: 200 | [Create Outlook Calendar](https://docs.meetstream.ai/api-reference/api-endpoints/calendar/create-outlook-calendar) |

## Google signed-in bots

| Method and path | What it does | Request | Docs |
|---|---|---|---|
| `POST /api/v1/google-login-domains` | Register a Google Workspace domain so signed-in bots can authenticate with accounts on it and skip the Google Meet lobby. | body: **sso_workspace_domain** + 2 optional; responses: 200 | [Create Google Domain](https://docs.meetstream.ai/api-reference/api-endpoints/google-signed-in-bots/create-google-domain) |
| `GET /api/v1/google-login-domains` | List the Google Workspace domains registered for signed-in bots in your workspace, with the status of each. | responses: 200 | [List Google Domains](https://docs.meetstream.ai/api-reference/api-endpoints/google-signed-in-bots/list-google-domains) |
| `GET /api/v1/google-login-domains/{domain}` | Get the stored configuration for one registered Google Workspace domain used by signed-in bots. | responses: 200 | [Get Google Domain](https://docs.meetstream.ai/api-reference/api-endpoints/google-signed-in-bots/get-google-domain) |
| `PATCH /api/v1/google-login-domains/{domain}` | Update a registered Google Workspace domain used by signed-in bots, for example to change its credentials or status. | responses: 200 | [Update Google Domain](https://docs.meetstream.ai/api-reference/api-endpoints/google-signed-in-bots/update-google-domain) |
| `DELETE /api/v1/google-login-domains/{domain}` | Remove a Google Workspace domain from signed-in bots, so bots can no longer authenticate with accounts on that domain. | responses: 200 | [Delete Google Domain](https://docs.meetstream.ai/api-reference/api-endpoints/google-signed-in-bots/delete-google-domain) |
| `POST /api/v1/google-logins` | Add a Google account for bots to sign in as, so they join Google Meet as a named participant and bypass the lobby. | body: **domain**, **email**, **sso_private_key_pem**, **sso_cert_pem** + 1 optional; responses: 200 | [Create Google Login](https://docs.meetstream.ai/api-reference/api-endpoints/google-signed-in-bots/create-google-login) |
| `GET /api/v1/google-logins` | List the Google accounts available to signed-in bots in your workspace, with the status of each login. | query: domain; responses: 200 | [List Google Logins](https://docs.meetstream.ai/api-reference/api-endpoints/google-signed-in-bots/list-google-logins) |
| `GET /api/v1/google-logins/{login_id}` | Get one Google login used by signed-in bots. | query: domain; responses: 200, 400, 403, 404 | [Get Google Login](https://docs.meetstream.ai/api-reference/api-endpoints/google-signed-in-bots/get-google-login) |
| `PATCH /api/v1/google-logins/{login_id}` | Update a stored Google login used by signed-in bots, for example to rotate the credentials behind it. | body: **domain** + 3 optional; responses: 200 | [Update Google Login](https://docs.meetstream.ai/api-reference/api-endpoints/google-signed-in-bots/update-google-login) |
| `DELETE /api/v1/google-logins/{login_id}` | Delete a stored Google login so bots stop signing in with that account on Google Meet. | query: domain; responses: 200 | [Delete Google Login](https://docs.meetstream.ai/api-reference/api-endpoints/google-signed-in-bots/delete-google-login) |
